
# 📘 Assignment: Hangman Game Challenge

## 🎯 Objective

Build a classic Hangman game in Python to practice string manipulation, loops, conditional logic, and user input handling.

## 📝 Tasks

### 🛠️ Create Hangman Game Mechanics

#### Description
Implement the core Hangman logic so the player can guess letters, track progress, and either win or lose.

#### Requirements
Completed program should:

- Randomly select a hidden word from a predefined list
- Prompt the player to guess letters and update the displayed word state
- Show blanks for unknown letters and reveal correct guesses in place
- Track incorrect guesses and remaining attempts
- End the game with a win message when the word is fully guessed or a lose message when attempts run out

### 🛠️ Add Player Feedback and Replay Support

#### Description
Add clear game feedback after each guess and let the player choose whether to play again.

#### Requirements
Completed program should:

- Display the current progress of the word using underscores for missing letters
- Show letters already guessed and the number of remaining attempts after each guess
- Inform the player whether each guess was correct or incorrect
- Offer the player an option to play again when the game ends
